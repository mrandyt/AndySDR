AndySDR decoders folder
=======================

Put the free decoder programs here (any sub-folder is fine - AndySDR searches for the .exe):

  dsd-fme.exe      DMR, P25 Phase 1/2, NXDN, dPMR, YSF, M17, ProVoice, X2-TDMA
                   https://github.com/lwvmobile/dsd-fme  (Windows build from its Releases page)

  multimon-ng.exe  POCSAG 512/1200/2400, FLEX pagers, APRS, DTMF, ZVEI, EAS
                   https://github.com/EliasOenal/multimon-ng

  satdump.exe      Meteor-M N2-3 / N2-4 LRPT weather satellite images
                   https://www.satdump.org  (Windows portable zip)

WEFAX (HF weather fax) is built into AndySDR - nothing to install.

Open AndySDR > DECODERS tab: each decoder shows a green tick when its program is found.
